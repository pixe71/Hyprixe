# Hyprixe Wiki

Hyprixe is a dark Frosted Glass Hyprland desktop for **Debian 13 Trixie**.
The Wiki is the single maintained user guide; the project README is the overview.
NixOS support is planned, not implemented.

## Start here

- [Installation](Installation): requirements, native/VMware options and first login.
- [Keybindings](Keybindings): applications, workspaces, screenshots and media keys.

## Make it yours

- [Dynamic Wallpaper Theming](Dynamic-Theming): wallpaper, colours, enable/disable and SDDM.
- [Desktop components](Desktop): menus, bar, terminal, file manager, lock and session.
- [Customization](Customization): where to edit settings and how to apply them.

## Maintain and troubleshoot

- [Maintenance](Maintenance): update, verify, back up and restore.
- [Troubleshooting](Troubleshooting): common failures and recovery commands.
- [Architecture](Architecture): Core + Profiles and contribution rules.
- [Assets and credits](Assets): licenses, screenshots and release checks.

Run installation and maintenance commands from the checkout as your desktop
user. Sudo is requested only for the necessary system changes.
