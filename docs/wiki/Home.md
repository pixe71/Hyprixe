# Hyprixe

Hyprixe is a Frosted Glass Hyprland desktop configuration for Debian 13 Trixie.

## Links

- [Installation](Installation)
- [Keybindings](Keybindings)
- [Troubleshooting](Troubleshooting)
- [Full documentation](https://github.com/pixe71/hyprixe-debian/blob/main/docs/README.md)

## Main components

Hyprland, UWSM, Waybar, Rofi, Wlogout, Kitty, Zsh, Powerlevel10k,
Dolphin, Kvantum and SDDM.
